# LPK format

An `.lpk` file is a zstd-compressed SquashFS image with a JSON manifest and, for signed packages, a 104-byte Ed25519 trailer.

| Property | Value |
| :--- | :--- |
| Container | SquashFS |
| Compression | zstd (default level 15) |
| Manifest format | Schema v5 (`format_version: 5`) |
| Engine version | 6.0.0 |
| Signature | Ed25519, 104-byte embedded trailer |
| Extension | `.lpk` |

## Archive layout

Two payload layouts are supported.

### Assembly layout (`ulpm pack`)

```text
meta/
  manifest.json
  icon.png              # optional
root/
  AppRun                # or bin/<name>, usr/bin/<name>, ...
  lib/
  share/
```

The `root/` prefix is stripped when the application is mounted or extracted; the payload becomes the sandbox's `/app`.

### Pre-structured layout

A directory that already contains `meta/manifest.json` (or `manifest.json`) is packed as-is. This is used for rootfs images and custom layouts:

```text
meta/manifest.json
etc/
usr/
bin/
```

A rootfs is detected when:

- the top-level `type` or `kind` field is `rootfs`, `distro` or `os`, or
- the archive contains `root/etc` + `root/usr` with `root/bin`, or
- the archive contains `etc/` + `usr/` with `bin/`.

The sandbox executes a rootfs through a host-root namespace rather than the `/app` application layout.

## Manifest schema

Example generated by `ulpm pack`:

```json
{
  "format_version": 5,
  "id": "io.lpk.example",
  "name": "example",
  "version": "1.0.0",
  "arch": "amd64",
  "exec": "AppRun",
  "runtime": null,
  "dependencies": [],
  "shared": false,
  "permissions": {
    "network": true,
    "audio": true,
    "gui": true,
    "gpu": true,
    "filesystem": {
      "home": "isolated",
      "downloads": "read-write",
      "custom": []
    },
    "devices": {
      "dri": true,
      "input": true,
      "hidraw": false,
      "usb": false,
      "kvm": false
    },
    "dbus": {
      "session": {
        "talk": [],
        "own": []
      }
    }
  }
}
```

### Fields

| Field | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `format_version` | integer | No | Manifest schema, `1`-`5`. Defaults to `1` when absent; `ulpm pack` writes `5`. |
| `id` | string | Recommended | Stable app ID, 1-128 chars, `^[A-Za-z0-9][A-Za-z0-9._-]*$`, no `..`. |
| `name` | string | Recommended | Install name and launcher name. Same character rules as `id`; must not contain `/`. |
| `version` | string | Recommended | Defaults to `1.0.0`. `pack` accepts `[A-Za-z0-9.+_:~-]+`; install sanitizes to `[A-Za-z0-9.+_-]`. |
| `arch` | string | No | Target architecture, default `all`. See the allowed list below. |
| `exec` | string | No | Relative entrypoint, no leading `/`, no empty segments or `..`. Sandbox default: `bin/main`. |
| `type` / `kind` | string | No | `rootfs`, `distro` or `os` selects rootfs execution. |
| `dependencies` | array | No | Strings or objects; see [Dependencies](dependencies-transactions.md). |
| `runtime` | string / null | No | Shared runtime ID to bind into the sandbox. |
| `runtime_abi` | string / null | No | Runtime ABI axis; default `default` at execution. |
| `abi` | string / null | No | Alternative ABI field used by runtime packages and indexes. |
| `shared` | boolean | No | Marks a package as a shared runtime. Required by `ulpm runtime install`. |
| `permissions` | object | No | Declarative sandbox permissions. |
| `description` | string | No | Human-readable description used by repository indexes and search. |
| `chromium` | boolean | No | Requests Electron/Chromium compatibility flags inside the sandbox. |
| `network` | boolean | No | Legacy top-level network permission, used when `permissions` is absent. |

`ulpm pack` derives a missing ID as `io.lpk.<lowercase-name>` and a missing version as `1.0.0`.

If `meta/manifest.json` is absent at runtime, `lpk.json` is accepted as a fallback manifest path.

### Allowed architecture values

`x86_64`, `amd64`, `i386`, `i686`, `aarch64`, `arm64`, `armv7l`, `armv7`, `armhf`, `riscv64`, `ppc64le`, `s390x`, `loongarch64`, `mips64`, `mips`, `sparc64`, `all`, `any`, `noarch`.

The engine normalizes `x86_64` to `amd64`, `aarch64` to `arm64`, `armv7*` to `armhf`, and `i?86` to `i386`.

### Entrypoint resolution

For application packages, the sandbox looks for the manifest `exec` path, then `AppRun`, `bin/main` and `main` inside the payload. `ulpm pack` auto-detects in this order:

1. `AppRun`
2. `bin/main`
3. `main`
4. `bin/<name>`
5. `usr/bin/<name>`
6. The first executable identified by `file` in the payload

## Permissions reference

Permissions are declarative defaults. Local overrides are merged on top at runtime.

| Key | Values | Default (generated) | Effect |
| :--- | :--- | :--- | :--- |
| `network` | boolean | `true` | Share or unshare the network namespace |
| `audio` | boolean | `true` | Bind audio devices and PulseAudio/PipeWire sockets |
| `gui` | boolean | `true` | Bind X11/Wayland sockets and keep IPC shared |
| `gpu` | boolean | `true` | Bind `/dev/dri`, Vulkan, GLVND and NVIDIA devices |
| `filesystem.home` | `isolated`, `read`, `read-write` | `isolated` | Guest home, read-only host home, or read-write host home |
| `filesystem.downloads` | `read-write`, `read`, `none` | `read-write` | Host Downloads exposure |
| `filesystem.custom` | array of `{path, mode}` | `[]` | Additional host binds; `mode` is `ro`/`read` or read-write |
| `devices.dri` | boolean | `true` | `/dev/dri` |
| `devices.input` | boolean | `true` | `/dev/input`, `/dev/uinput`, joysticks |
| `devices.hidraw` | boolean | `false` | `/dev/hidraw*` |
| `devices.usb` | boolean | `false` | `/dev/bus/usb` |
| `devices.kvm` | boolean | `false` | `/dev/kvm` |
| `dbus.session.talk` | string array | `[]` | Extra `xdg-dbus-proxy --talk` rules |
| `dbus.session.own` | string array | `[]` | Extra `xdg-dbus-proxy --own` rules |

When a `permissions` object is present but omits `network`, the sandbox treats network as **false**. Older manifests without a `permissions` object use the top-level `network` value, defaulting to true. Declare permissions explicitly to avoid ambiguity.

Custom filesystem destinations must be absolute, must not be `/`, and cannot target `/proc`, `/sys`, `/dev` or `/run`.

## Signature trailer

Signed packages end with exactly 104 bytes:

```text
Offset  Size  Content
0       8     ASCII "ULPM_SIG"
8       32    Raw Ed25519 public key
40      64    Ed25519 signature
```

The signed message is the SHA-256 digest of the complete payload before the trailer. Verification streams the payload digest, reconstructs the DER public key, and verifies with OpenSSL. A legacy trailer layout (`public key | signature | "LPK_SIG\0"`) is also accepted.

Unsigned packages are valid LPK archives but are rejected by default. See [Security](security.md).

## Shared runtimes

A runtime is an LPK with:

```json
{
  "shared": true,
  "id": "org.example.runtime",
  "version": "1.0.0",
  "arch": "amd64",
  "runtime_abi": "glibc-2.39"
}
```

`ulpm runtime install` stores it at:

```text
~/.local/share/ulpm/runtimes/<id>/<version>/<arch>/<abi>/
```

An application requests it with:

```json
{
  "runtime": "org.example.runtime",
  "runtime_abi": "glibc-2.39"
}
```

At runtime, the runtime's `usr`, `lib`, `lib64` and `bin` are bound read-only into the sandbox. If the requested runtime is missing, ULPM falls back to the host base with a warning.

## Reproducibility

`ulpm pack` aims for deterministic output:

- File timestamps are normalized to `SOURCE_DATE_EPOCH` (default `0`).
- Directories become `0755`; executable files `0755`; other files `0644`.
- SquashFS uses `-all-root`, `-no-xattrs`, `-mkfs-time`, and `-reproducible` when supported.
- zstd compression level defaults to `15` and is configurable with `ULPM_ZSTD_LEVEL` (`1`-`22`).

The signature is deterministic for the same payload and key. Builds can still differ when the payload contents differ.

## Library bundling

For application packages, `ulpm pack` uses the host dynamic loader to resolve `DT_NEEDED` libraries recursively (up to 10 passes) and copies non-host-provided libraries into `root/lib`. Core system, graphics, audio and display libraries are intentionally excluded so that the host stack remains authoritative.

Disable bundling with `--no-scan`, `--fast`, or `ULPM_NO_SCAN=1`. Bundling is automatically skipped for rootfs packages.
